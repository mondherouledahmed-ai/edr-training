Alertes SOC & Traitement 🔔

Types d'alertes fréquentes et comment les traiter. Ouvre les fiches pour détails + STAR.

🔐 Multiples échecs d'authentification (4625) / Password Spray
TriageMITRE TA0006Event 4625

Détecte des tentatives infructueuses répétées depuis une IP/origine, potentiellement spray sur comptes. Vérifier logs auth, réputation IP, bloquer si nécessaire.

⚡ Ajout d'un compte admin / Élévation de privilèges
CritiqueMITRE TA00044672, 4720, 4728

Création ou ajout d'utilisateur à un groupe privilégié. Vérifier légitimité, origine, change tracking. Corréler avec tickets change management.

🧠 Dump LSASS / Tentative Mimikatz
CritiqueMITRE TA0006/TA0007Sysmon 10

Processus suspect accédant à LSASS (MiniDumpWriteDump, SeDebugPrivilege), extraction mémoire credential. Isolation immédiate.

📡 Beaconing C2 / Activité périodique réseau
TriageMITRE TA0011Netflow/Proxy

Connexions sortantes régulières vers hôte inconnu, JA3/SNI suspects, tailles fixes. Indicateurs de commande et contrôle.

⚙️ Installation de service suspect (7045)
TriageMITRE TA0003Event 7045

Nouveau service créé avec binaire inconnu ou chemin user-profile/temp. Persistance potentielle, vérifier légitimité.

📧 Phishing avec macro malveillante
CritiqueMITRE TA0001

Email avec pièce jointe Office contenant macro VBA. Sandbox détecte téléchargement externe, création processus PowerShell encodé.

🔒 Indicateurs ransomware précoces
CritiqueMITRE TA0040

Désactivation AV, suppression shadow copies (vssadmin), scan réseau SMB, chiffrement fichiers. Isoler immédiatement.

🔄 Mouvement latéral via SMB/PsExec
CritiqueMITRE TA0008

Connexions SMB multiples + création comptes admin + services distants. Pattern typique d'attaquant se déplaçant dans le réseau.

🌐 DNS Tunneling / Exfiltration DNS
TriageMITRE TA0011

Requêtes DNS avec FQDN très longs, fréquence élevée, domaine récent/inconnu. Indicateur d'exfiltration ou C2 via DNS.

🕸️ Web Shell détecté sur serveur IIS/Apache
CritiqueMITRE TA0003

Fichier .aspx/.php suspect dans wwwroot, accès web avec commandes shell, création processus depuis w3wp.exe. Backdoor persistant.

🎫 Kerberoasting / Ticket Requests massifs
CritiqueMITRE TA0006

Event 4769 avec RC4 encryption, multiples SPN requests, compte utilisateur standard. Tentative extraction hash Kerberos.
