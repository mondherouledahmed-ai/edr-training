Alertes SOC & Traitement 🔔

Types d'alertes fréquentes et comment les traiter. Ouvre les fiches pour détails + STAR.

🔐 Multiples échecs d'authentification (4625) / Password Spray
Triage MITRE TA0006 Event 4625

Détecte des tentatives infructueuses répétées depuis une IP/origine, potentiellement spray sur comptes. Vérifier logs auth, réputation IP, bloquer si nécessaire.

⚡ Ajout d'un compte admin / Élévation de privilèges
Critique MITRE TA0004 4672, 4720, 4728

Création ou ajout d'utilisateur à un groupe privilégié. Vérifier légitimité, origine, change tracking. Corréler avec tickets change management.

🧠 Dump LSASS / Tentative Mimikatz
Critique MITRE TA0006/TA0007 Sysmon 10

Processus suspect accédant à LSASS (MiniDumpWriteDump, SeDebugPrivilege), extraction mémoire credential. Isolation immédiate.

📡 Beaconing C2 / Activité périodique réseau
Triage MITRE TA0011 Netflow/Proxy

Connexions sortantes régulières vers hôte inconnu, JA3/SNI suspects, tailles fixes. Indicateurs de commande et contrôle.

⚙️ Installation de service suspect (7045)
Triage MITRE TA0003 Event 7045

Nouveau service créé avec binaire inconnu ou chemin user-profile/temp. Persistance potentielle, vérifier légitimité.

📧 Phishing avec macro malveillante
Critique MITRE TA0001

Email avec pièce jointe Office contenant macro VBA. Sandbox détecte téléchargement externe, création processus PowerShell encodé.

🔒 Indicateurs ransomware précoces
Critique MITRE TA0040

Désactivation AV, suppression shadow copies (vssadmin), scan réseau SMB, chiffrement fichiers. Isoler immédiatement.

🔄 Mouvement latéral via SMB/PsExec
Critique MITRE TA0008

Connexions SMB multiples + création comptes admin + services distants. Pattern typique d'attaquant se déplaçant dans le réseau.

🌐 DNS Tunneling / Exfiltration DNS
Triage MITRE TA0011

Requêtes DNS avec FQDN très longs, fréquence élevée, domaine récent/inconnu. Indicateur d'exfiltration ou C2 via DNS.

🕸️ Web Shell détecté sur serveur IIS/Apache
Critique MITRE TA0003

Fichier .aspx/.php suspect dans wwwroot, accès web avec commandes shell, création processus depuis w3wp.exe. Backdoor persistant.

🎫 Kerberoasting / Ticket Requests massifs
Critique MITRE TA0006

Event 4769 avec RC4 encryption, multiples SPN requests, compte utilisateur standard. Tentative extraction hash Kerberos.

🏆 Golden Ticket / Forged Kerberos TGT
Critique MITRE TA0006

TGT avec durée de vie anormale (10 ans), compte inexistant ou désactivé, absence Event 4768 correspondant. Compromission KRBTGT.

⚡ PowerShell encodé Base64 / Obfusqué
Triage MITRE TA0002

Commande PowerShell avec -enc, -w hidden, bypass execution policy. Décodage révèle téléchargement, injection mémoire.

🖥️ RDP Hijacking / Session Shadowing
Critique MITRE TA0008

Utilisation tscon.exe ou query session, attachement session RDP existante sans authentification. Prise de contrôle session utilisateur.

⏰ Tâche planifiée suspecte / Schtasks
Triage MITRE TA0003

Event 4698, création tâche avec action PowerShell/script, exécution récurrente ou au démarrage. Persistance classique.

🔑 Modification Registry Run Key
Triage MITRE TA0003

Sysmon Event 13, modification HKLM/HKCU Run, RunOnce avec binaire suspect. Persistance au démarrage système/utilisateur.

💉 SQL Injection sur application web
Critique MITRE TA0001

WAF détecte payload SQLi (UNION SELECT, ' OR 1=1), logs applicatifs montrent requêtes anormales, dump base possible.

🔮 WMI Event Subscription / Persistence
Critique MITRE TA0003

Création Event Filter/Consumer WMI, exécution code sans processus visible. Détection Sysmon 19/20/21 ou WMI-Activity logs.

📤 Exfiltration via FTP/SFTP
Critique MITRE TA0010

Transferts FTP sortants inhabituels, volume important, destination externe inconnue. Vérifier DLP, proxy, firewall logs.

💊 DLL Injection / Process Hollowing
Critique MITRE TA0005

Sysmon Event 7, DLL chargée dans processus légitime, call CreateRemoteThread. EDR détecte injection mémoire, masquage malware.

🔐 Pass-the-Hash / NTLM Relay
Critique MITRE TA0008

Authentifications NTLM multiples avec mêmes hashes, sans Kerberos, Event 4624 Type 3. Mouvement latéral sans password.

☁️ Accès cloud non autorisé (Azure/AWS)
Critique MITRE TA0001

Connexion depuis IP/pays inhabituel, MFA bypass, création ressources, modification IAM. Logs CloudTrail/Azure AD Sign-ins.

📱 MFA Fatigue / Prompt Bombing
Triage MITRE TA0006

Multiples prompts MFA push sur courte période, utilisateur cède et approuve. Indicateur credentials compromis + social engineering.

🌐 Dump credentials navigateur
Triage MITRE TA0006

Accès fichiers Login Data (Chrome), key4.db (Firefox), processus lisant Credential Manager. Extraction passwords sauvegardés.

🧠 Mimikatz sekurlsa::logonpasswords
Critique MITRE TA0006

Accès mémoire LSASS, lecture structures credential, Event 4673 SeDebugPrivilege, EDR IOA. Extraction plaintext passwords.

⚠️ Exploitation ZeroLogon CVE-2020-1472
Critique MITRE TA0006

Netlogon RPC avec authentification nulle, reset password compte machine DC, Event 5805. Prise contrôle domaine.

🖨️ PrintNightmare exploitation CVE-2021-34527
Critique MITRE TA0004

RpcAddPrinterDriverEx abuse, chargement DLL malveillante, élévation SYSTEM. Logs Sysmon 3/11, Event 316 Print Service.

💾 Malware via périphérique USB
Triage MITRE TA0001

Device plug Event 6416, AutoRun exécution, création processus suspect depuis removable media. Vecteur initial infection.

🔄 Mouvement latéral via DCOM
Critique MITRE TA0008

Utilisation MMC20.Application, ShellBrowserWindow DCOM objects, exécution code distant. Alternative WMI/PsExec plus furtive.

📥 DCSync Attack / Replication malveillante
Critique MITRE TA0006

Requêtes DS-Replication-Get-Changes, Event 4662 accès AD objects, extraction NTLM hashes via DCSync (Mimikatz).

🔑 Credential Stuffing / Liste credentials volés
Triage MITRE TA0006

Tentatives login multiples IP unique, couples user:pass différents, source compromise lists. Pattern distinct du spray.

🚪 Backdoor SSH / Authorized_keys malveillant
Critique MITRE TA0003

Ajout clé SSH inconnue dans ~/.ssh/authorized_keys, connexions SSH sans password, persistance Linux. Audit logs Syslog.

🐳 Container Escape / Breakout Docker
Critique MITRE TA0004

Accès /proc filesystem host, montage volumes sensibles, capabilities abuse CAP_SYS_ADMIN. Sortie containeur vers hôte.

🔌 Abus API / Rate limiting bypass
Triage MITRE TA0040

Requêtes API excessive, rotation IP/User-Agents, endpoints sensibles, extraction données. Logs API Gateway, JWT invalides.

🎭 XSS Stored / Cross-Site Scripting persistant
Triage MITRE TA0001

Script malveillant injecté en base, exécution côté client, vol cookies/session. WAF détecte <script>, logs applicatifs.

☕ Log4Shell exploitation CVE-2021-44228
Critique MITRE TA0001

Payload JNDI ${jndi:ldap://}, requête LDAP externe, téléchargement classe Java, RCE. Logs applicatifs Java, network.

📦 Supply Chain Attack / Dépendance compromise
Critique MITRE TA0001

Package npm/pip malveillant, typosquatting, backdoor dans librairie légitime. Audit dependencies, hash vérification.

🎫 Token Theft / Session Hijacking
Critique MITRE TA0006

Vol JWT/OAuth token, réutilisation autre IP, accès API sans authentification. Logs anomalies géo, device fingerprint.

👤 Menace interne / Insider Threat
Triage MITRE TA0010

Employé accède données hors scope, téléchargements massifs avant départ, accès hors horaires. UEBA + DLP + HR correlation.

🤖 IoT Botnet / Mirai-like infection
Critique MITRE TA0011

Devices IoT avec credentials par défaut, scan réseau automatisé, DDoS commands. Netflow, telnet/SSH brute force.

💰 Cryptojacking / Mining malveillant
Triage MITRE TA0040

CPU spike anormal, connexions mining pools (Monero), processus xmrig/ccminer. Impact performance, coût électricité.

☁️ S3 Bucket public / Misconfiguration cloud
Critique MITRE TA0040

Bucket S3 public, données sensibles exposées, accès anonyme. CloudTrail logs, CSPM alerts, scanning externe.

Q&A SOC Professionnel 💬

Méthodologie: Détection → Qualification → Corrélation → Analyse comportementale (UEBA) → Réponse → Reporting

Questions d'entretien essentielles

  • L1 vs L2: L1 qualifie/faux positifs; L2 investigue/corrèle/répond
  • Faux positif: Alerte valide techniquement mais activité légitime
  • Qualifier une alerte: Logs + contexte + comportement + corrélation
  • MITRE ATT&CK: Mapper tactiques/techniques pour détection & réponses
  • SIEM saturé: Réduire faux positifs via corrélation, contexte, UEBA

🎯 Question RH Piège

« Comment êtes-vous opérationnel sans expérience SOC dédiée ? »

Réponse PRO: J'ai travaillé sur des environnements managés SOC avec logs réels (WAF, firewalls, SIEM). J'ai l'habitude de qualifier les alertes, faire de la corrélation multi-logs et distinguer faux positifs des incidents réels. Je travaille toujours avec une méthodologie SOC claire: détection, qualification, corrélation, analyse comportementale et reporting.

💡 Question Technique L1/L2

« Une alerte SIEM arrive, que faites-vous en premier ? »

Réponse PRO: Je commence toujours par qualifier l'alerte: je vérifie la source, le contexte, puis je corrèle avec d'autres logs avant toute action. Je ne bloque jamais sans comprendre si c'est un vrai incident ou un faux positif.

40+ Scénarios réalistes

1️⃣ Brute Force SSH (Linux)
Triage

Contexte: Échecs SSH multiples depuis IP externe
Logs: /var/log/auth.log ou /var/log/secure
Actions: Rechercher "Failed password for" → IP, utilisateur. Si >5-10 échecs → bloquer firewall/fail2ban. Vérifier compte, propagation autres hôtes. Prévention: clés SSH, désactiver password login.

2️⃣ Email Phishing
Critique

Contexte: Utilisateur reçoit mail suspect avec .docm
Actions: Vérifier expéditeur/headers, sandbox URL. Analyse SIEM/Proxy. Isoler poste si clic, quarantaine mail, informer utilisateur. Ticket SOC avec verdict.

14️⃣ Faux positif brute force SSH (interne)
Faux Positif

Comment qualifier: IP interne + compte technique (svc_backup) → corréler avec logs backup/cron/Ansible/Bastion. Si activité récurrente légitime → faux positif documenté. Checklist: IP interne connue, compte technique, horaire cohérent, activité récurrente, documenter SIEM.

16️⃣ UEBA: Connexion AD anormale
Comportemental

Contexte: Compte AD connexion 02h du matin, nouveau pays, serveur sensible
Analyse: Comparer habitudes (heures/pays/serveurs). Vérifier VPN/astreinte. Corréler logs VPN/AD/serveur. Si anomalie confirmée → reset PW + investigation. Phrase clé: « Ce n'est pas l'événement seul, mais l'écart comportemental qui déclenche l'incident. »

EDR Investigation 🔍

🎓 Formation complète EDR (HarfangLab‑like) • Détection • Investigation • Protection • Management • TI

🎯 Objectifs finaux

  • Exploiter un EDR en production
  • Investiguer un incident de bout en bout
  • Faire du Threat Hunting
  • Expliquer chaque module en entretien
  • Construire un playbook SOC EDR

📋 Checklist Investigation

  • Contexte: utilisateur, machine, sensibilité, exposition réseau
  • Processus: arbre, parents, horodatage, modules, signature/code-sign
  • Fichiers: hash, réputation VT, persistance (RunKeys, services, tâches)
  • Réseau: destinations, ports, fréquence, JA3/SNI, proxy logs
  • Mémoire: handles LSASS, injections, ETW patching
  • EDR: politiques, tamper, exclusions abusives

⚡ Actions

  • Isoler l'hôte, bloquer hachage/domaines/IOC
  • Collecte: triage bundle (proc, reg, services, network, autoruns)
  • Recherche latérale: events voisins, mêmes IOC, même user
  • Remédiation: supprimer persistance, patch, réinitialiser secrets
  • Améliorer détection: règle EDR, corrélations SIEM, playbook SOAR

🧠 PARTIE 5 — THREAT INTELLIGENCE

  • 15. YARA: détection malware custom, hunting mémoire
  • 16. Sigma: détection comportementale

Exemple YARA

rule Suspicious_PowerShell_Base64 {
    meta:
      author = "SOC"
      description = "Powershell EncodedCommand"
    strings:
      $enc = /-enc(odedCommand)?\s+[A-Za-z0-9+/=]{12,}/ nocase
      $ps  = "powershell" nocase
      $wget = "Invoke-WebRequest" nocase
    condition:
      $enc and 1 of ($ps, $wget)
  }

Exemple Sigma

title: Suspicious PowerShell EncodedCommand
  id: 1f0e-ps-enc
  status: experimental
  logsource:
    product: windows
    category: process_creation
  detection:
    selection:
      CommandLine|contains|all:
        - powershell
        - -enc
    condition: selection
  level: high
  references:
    - https://attack.mitre.org/techniques/T1059/001/

Splunk: SPL & Sourcetypes 🔎

Requêtes copiables pour chaque scénario

🔐 Password Spray Detection

index=wineventlog sourcetype=WinEventLog:Security EventCode=4625
| stats count as failures by src_ip, user, host
| where failures > 20
| sort - failures

🧪 Fileless PowerShell (EncodedCommand)

index=wineventlog sourcetype=WinEventLog:Security EventCode=4688
| search New_Process_Name=*\\powershell.exe CommandLine="*-enc*" OR CommandLine="*-EncodedCommand*"
| table _time, host, user, New_Process_Name, CommandLine, Parent_Process_Name
index=wineventlog sourcetype=XmlWinEventLog:Microsoft-Windows-PowerShell/Operational EventCode=4104
| search Message="*EncodedCommand*" OR Message="*FromBase64String*"
| table _time, host, user, Message

🔄 Lateral Movement SMB / PsExec

index=wineventlog sourcetype=WinEventLog:Security (EventCode=4624 Logon_Type=3)
| stats count by src_ip, Account_Name, host
| sort - count
index=wineventlog sourcetype=WinEventLog:System EventCode=7045
| search Service_Name="*PSEXESVC*" OR ImagePath="*\\\\ADMIN$\\*"
| table _time, host, Service_Name, ImagePath, Account_Name

🧠 LSASS Dump (Sysmon 10)

index=sysmon sourcetype=XmlWinEventLog:Microsoft-Windows-Sysmon/Operational EventCode=10
| search TargetImage="*\\lsass.exe"
| table _time, host, SourceImage, TargetImage, GrantedAccess, CallTrace

🧰 LOLBins (certutil/bitsadmin/regsvr32)

index=wineventlog sourcetype=WinEventLog:Security EventCode=4688
| search (New_Process_Name="*\\certutil.exe" OR New_Process_Name="*\\bitsadmin.exe" OR New_Process_Name="*\\regsvr32.exe")
| table _time, host, user, New_Process_Name, CommandLine, Parent_Process_Name

🔑 Registry Persistence (Sysmon 13)

index=sysmon sourcetype=XmlWinEventLog:Microsoft-Windows-Sysmon/Operational EventCode=13
| search (TargetObject="*\\Run" OR TargetObject="*\\RunOnce")
| table _time, host, User, Image, TargetObject, Details

🌐 C2 HTTPS (Sysmon 3)

index=sysmon sourcetype=XmlWinEventLog:Microsoft-Windows-Sysmon/Operational EventCode=3
| eval sni=coalesce(dns_query, DestinationHostname)
| search sni!="" AND (user_agent!="" OR DestinationPort=443)
| stats count, values(DestinationIp) as ips by host, Image, sni
| where count > 20
| sort - count

⏰ Tâches planifiées (4698)

index=wineventlog sourcetype=WinEventLog:Security EventCode=4698
| table _time, host, SubjectUserName, TaskName, Command, Arguments

⚡ Privilege Escalation

index=wineventlog sourcetype=WinEventLog:Security (EventCode=4720 OR EventCode=4728 OR EventCode=4672)
| eval target_user=coalesce(TargetUserName, MemberName)
| stats latest(_time) as last_seen, values(EventCode) as events by target_user, src_user, host
| convert ctime(last_seen)

🧠 LSASS Access Detection

index=sysmon sourcetype=XmlWinEventLog:Microsoft-Windows-Sysmon/Operational EventCode=10
| search TargetImage=*\\lsass.exe GrantedAccess=0x1fffff
| stats earliest(_time) as first, latest(_time) as last by Computer, Image, SourceImage, CallTrace
| convert ctime(*)

❓ Question d’entretien

            
Q: Différence entre un event EDR et une alerte ?
R: Un security event est une donnée brute issue de la télémétrie. Une alerte est générée après corrélation, scoring ou matching avec une règle.

4️⃣ Antivirus (EDR ≠ AV classique)

            
    
              
  • AV: Signature, réactif, fichier
    • 
              
  • EDR: Comportement, proactif, chaîne d’attaque
    • 
              
  • Détecte: ransomware sans signature, LOLBins (powershell, certutil), living off the land
    • 
            

            
❓ Entretien: Pourquoi un malware peut passer l’AV mais pas l’EDR ? Réponse: L’EDR détecte le comportement et la chaîne d’attaque, pas seulement le hash.

    rule Suspicious_PowerShell_Base64 {
    meta:
      author = "SOC"
      description = "Powershell EncodedCommand"
